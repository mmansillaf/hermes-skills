# Plantilla: Biblia de Producción para Anuncio B2B LegalTech (60s)

## Cuándo usar esta plantilla

Reemplazar contenidos entre {CORCHETES} con los datos específicos del producto/servicio.

## 1. Estructura Narrativa (60 segundos)

| Segmento | Tiempo | Función |
|----------|--------|---------|
| Hook | 0:00-0:05 | Impacto + pregunta retórica que valida el dolor |
| Problema | 0:05-0:15 | Visualización del problema |
| Solución | 0:15-0:30 | Revelación del producto + claim principal |
| Demo | 0:30-0:45 | UI/producto en acción |
| Beneficio | 0:45-0:55 | Resultado: cliente satisfecho |
| CTA | 0:55-1:00 | Llamada a la acción |

## 2. Storyboard Detallado

### Escena 1 — Hook (0:00-0:05)
- **Visual:** Profesional frustrado en escritorio, desorden, múltiples pestañas abiertas
- **Texto pantalla:** "¿CUÁNTAS HORAS PIERDES EN {TAREA_DOLOROSA}?"
- **VO:** "¿Y si pudieras {BENEFICIO_CLAVE} en segundos?"
- **Música:** Tensión leve (cuerdas graves, 60-70 BPM)

### Escena 2 — Problema (0:05-0:15)
- **Visual:** Montaje rápido: {ESCENAS_DOLOR} (ej: libros, carga lenta, reloj, frustración)
- **Texto:** "{DESCRIPCION_PROBLEMA}"
- **VO:** "{NARRACION_PROBLEMA}"
- **Música:** Tensión creciente

### Escena 3 — Solución (0:15-0:25)
- **Visual:** Corte a negro → Logo apareciendo + {METRICAS_CLAVE}
- **Texto:** "{NOMBRE_PRODUCTO}" + "{METRICA_1}" + "{METRICA_2}"
- **VO:** "Conoce {NOMBRE_PRODUCTO}, {DESCRIPCION_BENEFICIO}"
- **Música:** Cambio a tono ascendente (100-110 BPM)

### Escena 4 — Demo (0:25-0:45)
- **Visual:** Split screen: 70% UI producto + 30% usuario asombrado
- **Acciones:** {DEMO_PASOS} (ej: búsqueda lenguaje natural, resultados en segundos)
- **VO:** "{NARRACION_DEMO}"
- **Música:** Tech pulse (110-120 BPM)

### Escena 5 — Beneficio (0:45-0:55)
- **Visual:** Cliente triunfante, {ESCENA_EXITO}
- **Texto:** "{CLAIM_CIERRE}" (ej: "MENOS TIEMPO. MÁS RESULTADOS.")
- **VO:** "{NARRACION_BENEFICIO}"
- **Música:** Clímax emocional

### Escena 6 — CTA (0:55-1:00)
- **Visual:** Logo a pantalla completa + "PRUEBA GRATIS" + flecha + QR
- **VO:** "{NARRACION_CTA}"
- **Música:** Remate con fade out

## 8. Elementos de Contenido Obligatorios

Mensajes clave:
1. "{BENEFICIO_1}" — lenguaje natural / fácil de usar
2. "{BENEFICIO_2}" — segundos, no horas
3. "{METRICA_CLAVE}" — el número protagonista
4. "{BENEFICIO_3}" — actualización / precisión
5. "{BENEFICIO_4}" — hecho para el mercado local

Datos en pantalla:
- {METRICA_CLAVE} (con animación de contador)
- "↻ ACTUALIZACIÓN: {FRECUENCIA}"
- "⌛ {TIEMPO_RESULTADOS}"
- "{BENEFICIO_TECNOLOGICO}"

## 9. Checklist de Producción

- [ ] Guion final aprobado (VO + textos)
- [ ] Storyboard aprobado
- [ ] Casting actor/actriz con aspecto profesional
- [ ] Locación: oficina o set con utilería adecuada
- [ ] Vestuario: traje formal, camisa blanca
- [ ] Iluminación: 2700K + 5500K con gel azul
- [ ] Cámara: 4K@60fps (para slow motion)
- [ ] Micrófono: lavalier + shotgun
- [ ] Screen recording: UI limpia y rápida
- [ ] Post: color grading (azul dominante en solución)
- [ ] Versiones: 9:16, 16:9, 1:1
- [ ] Subtítulos obligatorios
- [ ] Música con licencia (Epidemic Sound / Artlist)
- [ ] Disclaimer legal visible si aplica
- [ ] Etiquetado de IA si aplica

## 10. Efectos de Sonido (SFX)

- Transición problema→solución: "Whoosh" ascendente + "ding"
- Búsqueda exitosa: "Tic-tac" acelerado + "pop"
- Métrica en pantalla: "Impact" o "stinger"
- CTA final: "Punch" seco
