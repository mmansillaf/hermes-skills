# Weighted Comparative Analysis Methodology

A reusable framework for evaluating multiple competing strategies, proposals, or options against each other using weighted criteria.

## Framework

### Step 1: Define Dimensions
Identify 8-12 dimensions/criteria relevant to the evaluation. Examples:
- Diagnóstico del problema
- Definición de público objetivo
- Estrategia de fotos
- Copywriting (título + descripción)
- Uso del presupuesto
- Estrategia de precios
- Scripts de comunicación
- Calendario/publicación
- Tácticas creativas/originales
- Cierre y logística

### Step 2: Assign Weights
Each dimension gets a weight (5-15%) summing to 100%.
Higher weight → more important criterion.

### Step 3: Score Each Option
Each option gets a score (1-10 per dimension).

### Step 4: Calculate Weighted Score
`Score = Sum(weight_i × score_i) for all dimensions`

### Step 5: Rank + Extract Best-of-Breed
Identify what each option does best and create a consolidated version.

## Template

| Dimensión | Peso | Opción A | Opción B | Opción C |
|---|---|---|---|---|
| Dim 1 | 15% | 7 | 9 | 6 |
| Dim 2 | 10% | 8 | 8 | 9 |
| Total | 100% | 7.5 | 8.9 | 7.2 |

## Identifying Gaps
After consolidation, check for GAPS — things that NO option covers.
Example gaps found in a real analysis:
- Objection handling for "es muy vieja/año"
- Cross-app inbox management
- Auto-reply scripts
- Payment security (fake transfer screenshots)
- Post-sale procedures

## Consolidation Strategy
1. Take the #1 ranked option as the structural base
2. Pull in specific tactics from lower-ranked options where they excel
3. Fill all identified gaps
