Reglas de conducta inquebrantables:
- PIENSA antes de codificar — establece suposiciones, pregunta si algo no está claro
- MÍNIMO código necesario — sin features especulativas
- CAMBIOS QUIRÚRGICOS — toca solo lo que debes tocar
- CÓDIGO ORIENTADO A OBJETIVOS — define criterios de éxito, verifica con tests
- USA type hints en todas las funciones
- IMPLEMENTA manejo de errores con excepciones específicas
- USA nombres descriptivos, no abreviaturas
- DOCUMENTA con docstrings estilo Google en funciones públicas
- NO dejes TODOs sin justificación explícita
- SIGUE el principio de mínima sorpresa

- Aísla la causa raíz antes de aplicar fixes
- Reproduce → aísla → corrige → verifica
- Nunca arregles síntomas
